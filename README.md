# Travel Agent Chatbot

An AI-based Travel Agent Chatbot that helps users plan personalized trips based on their travel preferences such as destination interests, budget, number of days, and season.

The system uses Natural Language Processing (NLP), Machine Learning, recommendation algorithms, and a custom itinerary generation algorithm to recommend suitable destinations, tourist places, and day-wise travel plans.

The chatbot also provides explanations for recommendations and allows users to modify their itinerary through natural language feedback.

---

## Project Overview

Travel planning often requires users to search through multiple sources to find suitable destinations, tourist attractions, travel durations, budgets, and activities.

This project provides an integrated travel planning system where the user can enter their requirements in natural language.

For example:

> I want a 4-day nature and adventure trip under ₹20,000 in winter.

The system extracts the user's preferences, recommends suitable Indian destinations, finds relevant tourist places, calculates recommendation scores, and generates a customized day-wise itinerary.

The user can also modify the generated itinerary through natural language instructions.

Example:

> Remove temples and add more adventure.

The system processes the modification, updates the recommendations, and generates a new itinerary.

---

# Project Objectives

The main objectives of the project are:

- Extract travel preferences from natural language.
- Recommend suitable Indian destinations.
- Recommend tourist places based on user interests.
- Consider budget and travel duration.
- Generate customized day-wise itineraries.
- Optimize sightseeing time.
- Provide explainable recommendations.
- Allow users to modify generated itineraries.
- Store user preferences, sessions, and itineraries in MySQL.
- Provide a complete chatbot-based travel planning experience.
